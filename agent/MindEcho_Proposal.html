Problem & Solution

情绪健康，正在成为 Z 世代的隐形危机

我们面对的问题比你想象的更普遍，也更隐蔽。

⚠️ 问题

  • 📊 3,000 万 中国青少年存在情绪障碍，但 85% 未获得任何专业帮助 [2][6]
  • 📱 现有方案要么太贵（心理咨询 ¥300-800/次），要么太沉重（需要正式就诊）[3]
  • 😰 68% 的厌学青少年伴有重度焦虑，但自己未必意识到情绪在恶化 [6]
  • 🧩 没有一款工具能 无感、自然、持续 地记录日常情绪变化
  • 🔇 社交焦虑、沟通障碍的年轻人缺乏自我觉察的入口

✅ MindEcho 的解法

  • 🎙️ 录下日常对话 — 像录音机一样自然，打开即录，无需任何心理准备
  • 🧠 AI 实时分析情绪 — 端侧规则引擎零延迟识别 7 种情绪状态，隐私安全
  • 📋 AI 生成每日报告 — 结合 DeepSeek 大模型，给出情绪趋势和改善建议
  • 🔒 数据本地优先 — 所有录音和分析默认存储在本地，云端仅按需启用
  • 🆓 零使用门槛 — 免费下载，无需穿戴设备，15 秒开始使用

为什么是 MindEcho？

三种核心差异，让 MindEcho 在同类产品中脱颖而出

🔊

语音才是最好的情绪入口

语速、音量、停顿、音调变化——这些人在日常对话中无意识流露的语音特征，比问卷更能真实反映情绪状态。MindEcho 通过声学特征提取（RMS 能量、过零率、停顿比）实现 7 种情绪分类，完全离线运行。

🔒

隐私优先，而非功能优先

所有录音和分析数据默认存储在本地设备。云端 API（DeepSeek 摘要、AssemblyAI 转录）仅在用户主动配置 API Key 后启用。不收集设备标识，随时可删除全部数据。

📈

从觉察到改善的完整闭环

录音 → 情绪分析 → AI 摘要 → 每日报告 → 趋势追踪。MindEcho 不是简单的情绪标签机，而是帮助用户建立「自我觉察→理解模式→主动改善」的完整闭环。

情绪分析引擎

端侧规则引擎，完整实现音频信号处理管线：WAV 读取 → 分帧（25ms/10ms shift）→ RMS 能量 + 过零率 → 5s 窗口聚合 → 7 类情绪分类。跨 session 能量归一化，置信度评分，arousal/valence 双维度输出。

✅ 已完成 AudioFeatureExtractor EmotionAnalyzer
